## Домашнее задание к работе 5 (вар.31)
### Условие задачи
Три груза (A, B, C кг) можно погрузить в контейнер, если вес каждого из них кратен пяти. Запишите условие, при котором диспетчерская система дает разрешение на погрузку.
### Формализация
Условие "вес каждого кратен пяти" означает, что остаток от деления каждого веса на 5 должен быть равен нулю. Поскольку условие должно выполняться для всех трех грузов одновременно, используется логическое И (&&).
Логическая операция: (A % 5 == 0) && (B % 5 == 0) && (C % 5 == 0). Если хотя бы один груз весит, например, 7 кг (7 % 5 = 2), то условие вернет 0 (ложь), и погрузка будет запрещена.
Программа выводит 1, если погрузка разрешена, и 0, если запрещена.

### 1. Реализация программы
```
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

void zadanie1()
{
    int A, B, C;
    int condition;

    printf("СИСТЕМА ДОСТАВКИ ГРУЗОВ\n");
    printf("Введите вес трех грузов (A, B, C): ");
    scanf("%d %d %d", &A, &B, &C);

    // каждый вес кратен 5
    condition = (A % 5 == 0) && (B % 5 == 0) && (C % 5 == 0);

    printf("Разрешение на погрузку (1 - да, 0 - нет): %d\n", condition);
}

int main() {
    setlocale(LC_ALL, ".UTF-8");
    zadanie1();

    return 0;
}
```
